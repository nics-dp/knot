# anydoc 轉換評估（SPEC 5.2，M3 開始前）

本檔只記錄轉換品質，不收錄任何來源內容。測試檔為使用者提供的真實參考資料，放在 repo 根目錄（已列入 `.gitignore`），轉換結果在 `local/sources/`（不進 git）。

## 初步結果（2026-10-26，anydoc @firecrawl/anydoc 0.2.4）

| 檔案 | 大小 | 轉換時間 | Markdown | 切出的區塊 |
|---|---|---|---|---|
| 技術文件（PDF） | 32 MB | 0.7 秒 | 324 KB | 段落 466、表格 95 |
| 輔導報告（PDF） | 39 MB | 0.5 秒 | 186 KB | 段落 327、表格 86 |

- **PDF 換頁位置：** 未保留，輸出中沒有任何頁碼資訊。→ 頁碼標記 `<!-- page: N -->` 無法自動產生；區塊位置目前只能用所屬標題表示。
- **標題：** 有輸出 Markdown 標題，但層級依字級推測，與文件實際章節層級不一致（例如封面文字成為 `#`，部分章節標題沒有成為標題）。→ 標題適合作為區塊分組，不適合直接產生卡片樹。
- **表格：** 轉為 GFM 表格，欄數 2–14 不等，可以正確切成表格區塊。內容品質尚未逐一檢查。
- **中文：** 正常輸出。部分字元為相容字（例如「⼯」「⼈」等 CJK 部首補充字），搜尋時需要正規化（NFKC）。
- **雜訊：** 頁首、頁碼等短行以「少於 8 字不成為區塊」過濾。
