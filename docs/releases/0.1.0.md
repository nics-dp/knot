第一版。

## 功能

- **卡片樹：** 章、節、項、款四層標題與段落、引言、表格、圖；拖曳重組；章可以標為附錄（附錄 A、A.1）。
- **全文與編輯：** 全文頁、段落編輯區、本文編輯器（清單、事實引用、交互參照）、目標字數。
- **素材與事實：** agent 從原始資料節錄素材與表格，數字記成事實（Knot 檢查值確實出現在素材中），素材掛到段落成為依據。
- **協作：** 卡片上的留言與待辦、卡片歷程與前一版比較、復原；段落修改後，依賴它的段落自動留下待辦。
- **LaTeX 匯出：** 整份報告匯出成 zip 草稿（`main.tex`、每章一個檔、每張表與圖各一個檔）。
- **agent 介面：** MCP 端點與四個 skill：規劃（`knot-planning`）、匯入（`knot-import`）、撰寫（`knot-writing`）、處理待辦（`knot-todos`）。

## 安裝

見 README。映像：`ghcr.io/nics-dp/knot:0.1.0`（Mac M 晶片與 Windows 都適用）；skill：下方附件 `knot-skills-0.1.0.zip`。

## 支援的環境

- macOS（Apple Silicon）與 Windows（x86_64），皆使用 Docker Desktop。
- agent 目前只支援 Claude Code。
